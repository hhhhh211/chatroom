# C++ 高并发聊天室开发文档

## 技术栈

- 后端：C++20
- 网络通信：Boost.Asio + Boost.Beast
- 实时协议：WebSocket
- 构建工具：CMake
- 包管理：vcpkg
- 前端：Vue 3 + Vite + TypeScript
- 数据库：MySQL
- Redis：在线状态和多实例消息广播
- 部署：Docker Compose + Nginx

## 阶段性开发规划

### 第 0 阶段：项目骨架和文档

目标：

- 创建基础目录。
- 创建 README.md。
- 创建 docs/开发文档.md。
- 创建后端 CMakeLists.txt。
- 创建最小 main.cpp。

验收标准：

- 项目结构清晰。
- README 能说明项目架构。
- 开发文档包含技术栈、目录结构、开发阶段。

### 第 1 阶段：最小 WebSocket 聊天室

目标：

- C++ 后端启动 WebSocket 服务。
- 浏览器可以连接后端。
- 一个用户发送消息，所有连接用户都能收到。
- 消息只存在内存中，不入库。

验收标准：

- 打开两个浏览器页面可以互相聊天。

### 第 2 阶段：多房间

目标：

- WebSocket 连接支持 room_id。
- 后端按房间管理连接。
- 消息只广播给同房间用户。

验收标准：

- 房间 A 和房间 B 消息互不影响。

### 第 3 阶段：前端页面

目标：

- Vue 页面输入昵称和房间号。
- 显示消息列表。
- 支持发送消息。
- WebSocket 断开后给出简单提示。

验收标准：

- 不用手写 WebSocket 测试脚本，直接网页聊天。

### 第 4 阶段：消息持久化

目标：

- 创建 rooms、messages 表。
- 发送消息时写入数据库。
- 进入房间时加载最近消息。
- 数据库使用 MySQL。

验收标准：

- 刷新页面后还能看到历史消息。

### 第 5 阶段：Redis 多实例广播

目标：

- Redis Pub/Sub 广播消息。
- 多个 C++ 后端实例之间共享消息。
- 每个实例只负责本机 WebSocket 连接。
- 消息只由接收浏览器请求的实例写入数据库，其他实例只转发给本机连接。

验收标准：

- 用户连接到不同后端实例时仍能互相聊天。

### 第 6 阶段：高并发优化

目标：

- 心跳检测。
- 每个连接独立发送队列。
- 限制消息长度。
- 限制发送频率。
- 简单统计在线人数和房间人数。

验收标准：

- 大量连接时服务不被单个慢连接拖垮。
